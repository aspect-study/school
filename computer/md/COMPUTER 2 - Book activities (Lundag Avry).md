### Let's Test Ourselves — Complete the Steps (p. 52)
Box: Start, Settings, Choose a fit, Background, Personalization, Choose your picture
To change the desktop wallpaper, do the following:
1. Click the **Start** button.
2. Select the **Settings** icon on the left.
3. Select **Personalization**.
4. Select **Background**. Select the box underneath Background to choose between a picture, solid color, or slideshow for the background.
5. Underneath **Choose your picture**, select one of the options, or select Browse to choose one from the computer.

*(reverse side, lesson steps)* 1 Select Start button. 2 Select Settings icon on the left.

### Let's Test Ourselves — Match the Icons (p. 62)
1 monitor + globe = Network · 2 empty bin = Recycle Bin – empty · 3 monitor + keyboard = This PC ·
4 folder with page = Documents · 5 bin with papers = Recycle Bin – full

*(reverse side)* The common icons we can find on our desktop are the following:
1. The This PC icon explores and manages the contents of the computer drives.
2. The Documents stores computer documents and other files on our computers.
3. The Network shows the available network connections, computers, and devices.
4. The Recycle Bin stores the deleted files.
The icons on the desktop can be viewed using the viewing options: Large icons, Medium icons,
Small icons, Auto arrange icons, Align icons to grid, and Show desktop icons.
The icons on the desktop can be sorted using the following options: Name, Size, Item type, and Date modified.
