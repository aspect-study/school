# Sound packs: kid-friendly default, MOBA announcer kept as an option

Date: 2026-10-09. Builds on `2026-10-02` fx.js work (sound FX + streak call-outs); everything there still holds unless changed here.

## Why

The streak, finish and medal voices are real Mobile Legends, Valorant and League of Legends announcer clips
(`web/assets/sounds/*.mp3`). They are not kid-friendly in tone and carry copyright risk. The owner wants them kept as an
option but not as the default, and a choice in settings.

## Decisions

- **Two packs.** `kids` ("Happy Chimes", **the default**) and `battle` ("Battle announcer", the current behaviour,
  unchanged). One shared choice for quiz answers and for the questions in the 3D world (monsters, gifts, friends), since
  both already go through `Fx`.
- **Stored per device**, like the mute key: `study_fx_pack_v1` (`'kids'` or `'battle'`). An unknown or missing value
  means `kids`. Existing installs therefore switch to `kids` until someone picks `battle`.
- **Kid-friendly pack is original and generated in code**, no downloads, no licences, no voice: the speech fallback is
  off for this pack so nothing robotic plays.
- **The world's own sounds are not touched** (steps, pets, props, emotes, rides: Kenney CC0 and Mixkit free licence,
  credited in `tools/world-sounds.js`).

## Design

### `web/engine/fx.js`

- `PACKS = { kids: {...}, battle: {...} }`. Each pack holds `tiers` (at, word, say, clip, color, glow, notes, big, rays),
  `firstBlood`, `finishClips` (0 to 3 stars), `examClips` (2 and 3 stars), `medalClips` (1 to 3), `speech` (true only
  for `battle`) and `label`.
- `battle` is today's `TIERS`, `FIRST_BLOOD`, `FINISH_CLIPS`, `EXAM_CLIPS`, `MEDAL_CLIPS` moved into the table.
- `kids` tiers, same `at` values 2 to 8: "Nice!", "Great!", "Super!", "Wow!", "Amazing!", "Fantastic!", "Superstar!";
  first right answer of a round "Yay!". Bright colours, big tiers keep confetti and rays. Subtitles unchanged.
- `Fx.pack()` returns the active id; `Fx.setPack(id)` ignores unknown ids, writes the key, stops any playing clip and
  plays the pack's sample (the "Nice!" tier clip) unless muted.
- `tierFor`, `finishClip`, `medalClip`, `allClips` take the pack id (default `kids`); `correct`, `finish` and the medal
  popup read the active pack. The pointer-down warm-up loads only the active pack's clips.
- The speech fallback `say()` runs only when the pack's `speech` is true.
- Export `PACKS`, `PACK_KEY`, `DEFAULT_PACK` for tests.

### `tools/kid-sounds.js` (new)

Plain Node, no dependencies. Synthesizes the clips (xylophone, bell, sparkle and "boing" tones with short decays, a
rising happier tune per tier) and writes `web/assets/sounds/kids/*.wav`: tiers 2 to 8, first answer, finish 0 to 3
stars, exam 2 and 3 stars, medals 1 to 3 (wav keeps the tool dependency-free; the clips are short, so the size is
small). Re-running the tool regenerates the files identically. Credit line in the header: original, generated by this
script.

### Where it is chosen

- **Nav menu** (`web/engine/nav.js`): a "Sounds: Happy Chimes / Battle announcer" row under Sound on/off, a
  `menuitemradio`-style toggle that calls `Fx.setPack`. Hidden when `Fx.setPack` does not exist (same guard as the
  Sound row). Grade 2 shows "Filipino · English" per the text rules; buttons stay English only.
- **World Settings** (`web/world/world-main.js` `openSettings`, `web/world/text.js`): the same choice as a `setting()`
  row. Grade 2 pairs Filipino and English in the label; floating signs are unaffected.
- Both read and write the same key, so changing it in one place shows in the other.

## Error handling

- localStorage unavailable: `pack()` returns `kids`, `setPack` still switches for the page's lifetime via an in-memory
  value.
- A missing clip falls back as today: `battle` uses speech, `kids` stays silent but the synthesized beeps and the visual
  call-out still play.

## Testing

- `tests/fx.test.js`: both packs have all tiers 2 to 8, first answer, finish 0 to 3, exam 2 and 3, medals 1 to 3; no
  clip used twice within a pack; every referenced file exists on disk; `battle` values equal today's; default is `kids`;
  `setPack` rejects unknown ids; `speech` only on `battle`.
- Nav and world Settings: the row exists, switching updates `Fx.pack()`, a Grade 2 label is paired.
- `tests/pwa.test.js`: new clips in PRECACHE (`node tools/update-precache.js`).
- `tests/learner.test.js` and `storage.test.js`: `study_fx_pack_v1` stays a device-level key like `study_fx_muted_v1`.
- Run `node --test`, the lobby and game e2e scripts, and `node tests/e2e/world-e2e.js`.

## Out of scope

- Voice or animal-cheer packs, per-learner packs, a parent-page setting.
- Replacing or re-checking the world's own sound clips.
- Deleting the MOBA clips: they stay for the `battle` pack.
